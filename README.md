# episodio25

An English-language thematic media discovery app for movies and TV or anime episodes. The product will use SvelteKit, TMDB, shadcn-svelte, and Vercel to help people browse occasions such as Christmas, Halloween, school festivals, road trips, and seasonal events.

## Status

Planning and domain modeling are in progress. Implementation has not started.

The current design is documented in [`docs/plans/2026-08-20-episodios-tematicos-design.md`](docs/plans/2026-08-20-episodios-tematicos-design.md).

## Security

TMDB credentials must remain server-side. Local `.env` files are ignored and must never be committed.
